# Pizza-Sales-SQL-Analysis

## Project Objective
The objective of this project is to analyze pizza sales data using SQL and extract meaningful business insights related to orders, revenue, pizza categories, and customer ordering patterns.

## The dataset contains the following tables:
- Orders
- Order Details
- Pizzas
- Pizza Types

## Questions (KPIs)
- Retrieve the total number of orders placed.
- Calculate the total revenue generated from pizza sales.
- Identify the highest-priced pizza.
- Identify the most common pizza size ordered.
- List the top 5 most ordered pizza types along with their quantities.
- Find the total quantity of each pizza category ordered.
- Determine the top 3 pizza types based on revenue.
- Find the category-wise distribution of pizzas.
- Determine the top 3 pizza types based on revenue for each pizza category.
- Determine the distribution of orders by hour of the day.

## Process
- Imported the pizza sales dataset into MySQL.
- Created and organized the required database tables.
- Performed data analysis using SQL queries.
- Used JOIN operations to combine data from multiple tables.
- Used aggregate functions such as SUM(), COUNT(), and ROUND().
- Used GROUP BY and ORDER BY to analyze and organize the data.
- Extracted meaningful business insights from the pizza sales data.

## SQL Concepts Used
- SELECT
- JOIN
- GROUP BY
- ORDER BY
- COUNT()
- SUM()
- ROUND()
- LIMIT

## Project Insight
- Analyzed the total number of orders placed by customers.
- Calculated the total revenue generated from pizza sales.
- Identified the highest-priced and most popular pizzas.
- Analyzed pizza size preferences among customers.
- Identified the top-performing pizza types based on quantity and revenue.
- Analyzed category-wise pizza sales.
- Identified customer ordering patterns based on the hour of the day.

## Final Conclusion
The analysis provides valuable insights into pizza sales performance, customer preferences, and ordering patterns. These insights can help the business identify popular products, understand peak ordering hours, and make better decisions related to product offerings and sales strategies.
